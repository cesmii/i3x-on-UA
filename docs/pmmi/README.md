# PMMI PackML example: not distributed here

This folder holds two PMMI files that the working group used as a worked example (see `CLAUDE.md`, "PMMI / PackML example"). **They belong to PMMI and are not part of this repository**; the files are listed in `.gitignore`.

| File expected here | What it is | Where to get it |
|---|---|---|
| `Information Model - PMMI 01Jun.pdf` | One-page diagram of a PMMI machine model (PackML data on Machinery building blocks) | Not published; ask PMMI (<https://www.pmmi.org/>) or the i3X working group |
| `PMMI PackML MBB Example 601.xml` | NodeSet implementing part of that diagram (`http://pmmi.org/profiles/MachineExample`) | Same |

Nothing in the build or runtime needs these files.
